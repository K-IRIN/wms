## 4. 关键口径与实现对应

| 验收点 | 实现 | 证据 |
|---|---|---|
| 有界队列 1000 + 单发送线程 + 满丢最旧 | `service/agv/AgvPublisher.java` | `capacity=1000`、`maxQueue=791`、`dropped=0` |

| 路径纯函数、网格每 tick 注入、去掉 bfs 内 `deviceService.list()` | `service/agv/AgvPathPlanner.java` + `AgvGridView` record；`rebuildGridView(devices)` | Planner 1000 组随机网格等价测试 |
| 状态机/推进/回收/日志抽离，对外行为不变 | `service/agv/AgvTaskLifecycle.java`；引擎 `advanceTask/changeTaskStatus/recycleTask/...` 全部委托 | Lifecycle 7 条单测 + 30 分钟长跑 |
| 派单带 `status=0` 条件防重复派单 | `assignPendingTasks` 用 `update ... where id=? and status=0`，`claimed==0` 跳过 | 全库 `GROUP BY agv_id HAVING COUNT(*)>1` 为 0 |
| 慢客户端不阻塞 tick | 发送在独立 daemon 线程 | 3 个慢连接 + tick max 343ms（首 tick 抖动） |
